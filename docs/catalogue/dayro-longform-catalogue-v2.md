## 2. Verification and selection rules

- **Current full-programme rows:** taken from the cited existing discovery chunk. The source note records exact video ID and runtime, YouTube playabilityStatus OK, playableInEmbed true, an HTTP 200 privacy-enhanced embed, and the check date shown in the table. Check dates here are 2026-10-02 or 2026-10-03. Recheck before any future ingestion or promotion.
- **Threshold:** 20 minutes minimum for this catalogue, with multi-hour complete programmes first. Short excerpts are omitted from this section.
- **Classification:** the source title, display title, set type or tags must explicitly identify Dayro/Dayra. Artist names, playlist membership and release-album text alone are not sufficient. Mixed Lok Sahitya, devotional or Santvani programmes retain only source-backed descriptors.
- **Parts/chapters:** keep each published upload as its own row only when it has its own source video ID. Do not invent song chapters or part boundaries from neighbouring videos.
- **Deduplication:** video ID is the physical recording key. The current source-backed set has no repeated IDs. Playlist membership and duplicate legacy-index targets are not additional recordings.
