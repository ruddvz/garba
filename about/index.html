About PlayGarba

One place for Garba.
Built around listening.

PlayGarba is an open, community-built Gujarati Garba catalogue and player for songs, artists, releases, live sets and nonstop Garba.

Listen now ↗ View the project on GitHub ↗

THE IDEA

Make Garba easier to find, understand and keep playing.

The product is intentionally centred on Garba rather than trying to become a general-purpose music service.

01 · Catalogue Garba first.

Songs, artists, releases and longer sets are organised as a dedicated Gujarati Garba catalogue.

02 · Player Listening stays central.

Search, browsing, queue, favourites and Nonstop sit around one player instead of becoming separate products.

03 · Access Web first.

The live player works in a browser and can also be installed as a progressive web app on supported devices.

01 · PUBLIC SITE + LIVE PLAYER

Two addresses, two jobs.

playgarba.com is the public website. It explains the product, introduces the six Garba worlds, provides help and installation guidance, and sends listeners to the right place.

live.playgarba.com is the listening application. It owns the player, catalogue, PWA manifest, service worker and listening state.

Why separate them?

The split keeps the public site fast and editorial while letting the live player evolve around playback, mobile behaviour, caching and catalogue updates without turning every public page into part of the runtime.

02 · THE SIX WORLDS

A consistent courtyard, six musical entry points.

The visual system uses six worlds: Traditional, Dandiya, Devotional, Folk, Sanedo and Fusion. Each world keeps the same premium Gujarati courtyard language while shifting atmosphere and catalogue context.

TraditionalThe core starting point for traditional Garba listening.
DandiyaA dedicated Dandiya Raas listening context.
DevotionalDevotional Garba within the same player system.
FolkGujarati folk-led repertoire and related discovery.
SanedoSanedo as its own recognisable listening world.
FusionContemporary and crossover Garba listening.

03 · CATALOGUE

Discovery starts with what the music actually is.

The catalogue is source-driven. It keeps song and release records separate from the visual interface so collection work can grow without being tied to one screen design.

Search starts with title and artist matching, then can use Garba taxonomy, styles and aliases to support broader discovery. Nonstop sets are represented separately so a long performance is not forced into the same shape as a single track.

04 · PLAYBACK

One catalogue can point to more than one kind of source.

A catalogue item can resolve through different approved playback routes. Depending on the item, that can include direct audio or a cited external provider. The player keeps the surrounding Garba context stable even when the underlying source changes.

External providers retain control over their own availability, sign-in, advertising and provider-specific playback behaviour.

05 · PRODUCT PRINCIPLES

Keep the interface quieter than the music.

Responsive firstPhone, iPad and desktop are treated as distinct interaction contexts, not simple scaled versions of one layout.
Stable controlsTrack title changes and visual transitions should not make primary playback controls jump around.
Accessible motionDecorative movement is restrained and non-essential animation yields to reduced-motion preferences.
Truthful statesUnknown durations, failed catalogue loads and offline conditions should be shown clearly instead of being disguised as valid playback state.

06 · OPEN PROJECT

The project is visible.

PlayGarba is community-built and its repository is public. The project includes the player runtime, catalogue data, discovery records, PWA implementation, validation scripts and operating documentation.
