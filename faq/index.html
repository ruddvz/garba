01 · GETTING STARTED

Where should I start?

Which URL should I use for listening?

Use live.playgarba.com. It is the dedicated listening application. playgarba.com is the public website for guides, installation help and general information.

Do I need an account before I can use the player?

The current public guidance does not require an account step to start using the player. Open the live address and begin from the available listening controls.

Can I use PlayGarba without installing it?

Yes. Installation is optional. The live player works as a normal website, and installing it simply gives you an app-style launcher and standalone window where supported.

02 · INSTALLING

What does installing actually change?

Is PlayGarba in the App Store or Play Store?

You do not need an app-store download for the current PWA. Start from live.playgarba.com in a supported browser and use its install or Add to Home Screen action.

Which browser should I use on iPhone or iPad?

Use Safari for the clearest Apple web-app installation route. Open the live player, use Share, then Add to Home Screen and the web-app option shown by the current iOS version.

What about Android or desktop?

Chrome can install supported web apps on Android and desktop. Microsoft Edge also supports installing websites as apps. The dedicated install guide gives the current route for each.

03 · LISTENING

How is the player organised?

What are the six worlds?

Traditional, Dandiya, Devotional, Folk, Sanedo and Fusion are the six primary listening worlds used by the player.

What is Nonstop?

Nonstop is the route for longer Garba sets and continuous performances. It lives inside the same player rather than in a separate application.

Where do I search for a specific song or artist?

Use Browse Songs in the live player. On phones it opens as a bottom sheet; on larger screens it uses a wider browsing surface.

Can I save favourites or use a queue?

The player includes favourites and queue-related controls where the active listening context exposes them. The exact control set can vary with the current source and state.

04 · PLAYBACK SOURCES

Why can two tracks behave differently?

Does every catalogue item use the same audio source?

No. PlayGarba can resolve catalogue items to different approved playback routes, including direct audio and cited external providers.

Why might I see advertising or a sign-in request?

If a track uses an external provider, that provider controls its own advertising, authentication, availability and playback restrictions.

Can PlayGarba remove a provider's own restrictions?

No. PlayGarba can organise the catalogue and listening context, but it does not override the rules of an external playback provider.

05 · OFFLINE + UPDATES

What happens when the connection changes?

Does the installed app work offline?

The interface can cache its shell, offline page and selected static assets after a successful online visit. External audio and video are not silently downloaded, so normal playback still depends on an available source and network.

Do I need to reinstall PlayGarba to get updates?

Normally, no. The web app is designed to request fresh player code and catalogue data from the network while caching static assets more aggressively.

What should I do if something looks stale?

Reconnect to the internet and reopen or refresh the live player. The current runtime is designed to refresh catalogue data after reconnecting and when returning to a stale open tab.
