PWA install guide

Your Garba player.
One tap away.

PlayGarba is a progressive web app. You can keep using it in a browser, or install the live player to your home screen or desktop for a standalone app-style experience.

Open live.playgarba.com ↗ See my device instructions ↓

BEFORE YOU INSTALL

Install the player, not the public website.

The installable PlayGarba app lives on the dedicated listening origin. Start the installation from live.playgarba.com so the installed icon launches directly into the player.

01 · Address Use live.playgarba.com.

That is where the PWA manifest, service worker, player and catalogue are deployed.

02 · No store No App Store search required.

Install directly from a supported browser. You can also keep using the same player as a normal website.

03 · Updates The web app can update in place.

Player code and catalogue data are designed to check the network for fresh versions instead of requiring a fresh app download.

INSTALL BY DEVICE

Use the route that matches your device.

Browser menu wording can shift slightly between versions. The steps below match the current platform guidance and all begin from the live player.

Your device

Choose the matching instructions below.

Recommended route
iPhone and iPad

Safari

Apple's current web-app flow can place PlayGarba on your Home Screen and open it without the normal Safari browser chrome.

  1. Open live.playgarba.com in Safari.
  2. Tap the Share control.
  3. Choose Add to Home Screen.
  4. Turn on Open as Web App.
  5. Tap Add.

Chrome

After installation
Launching App shortcuts Updates Offline Removing the app

01 · LAUNCHING

Tap GARBA and go straight to the player.

The installed app is configured for a standalone display. Where the browser supports the launch behaviour, opening PlayGarba again should focus the existing app instead of creating unnecessary duplicate windows.

The installed start route includes a PWA source marker, but it remains the same live PlayGarba player and catalogue.

02 · SHORTCUTS

Some devices can jump straight into a Garba world.

The PlayGarba manifest currently publishes shortcuts for Traditional Garba, Dandiya Raas and Explore catalogue. Browsers and operating systems decide whether and where those shortcuts are exposed.

TraditionalLaunch directly into the Traditional Garba world where shortcuts are supported.
DandiyaOpen the Dandiya Raas world without navigating from the default player state.
Explore catalogueOpen the Explore catalogue directly from a supported app shortcut surface.
Normal launchTap the main PlayGarba icon to open the standard live player.

03 · UPDATES

You normally should not need to reinstall it.

PlayGarba's app code, CSS, manifest and catalogue data are set up to prefer fresh network versions when available. Static artwork can be cached more aggressively so repeat visits stay efficient.

If you return after the app has been closed for a while, it can refresh catalogue data and pick up newer player files through the normal web-app update path.

04 · OFFLINE

Installed does not mean downloaded music.

The service worker can keep the app shell, offline page and selected static assets available after an online visit. It does not silently save external provider audio or video for offline listening.

Expect internet for playback

If your connection drops, the interface can recover more gracefully than a normal uncached page, but normal music playback still depends on the available source and network.

05 · REMOVE

Remove it like another home-screen or desktop app.

On iPhone or iPad, touch and hold the PlayGarba icon and use the normal remove action. On Android, use the app's uninstall action. Chrome and Edge also let you manage installed web apps from their app-management screens.

You can always return to live.playgarba.com in a browser later and install it again.
