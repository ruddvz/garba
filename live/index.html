Use it your way
Browser Installed app Phone and tablet Desktop Connection loss

01 · BROWSER

No installation is required.

Open the live address in a browser and use PlayGarba normally. The PWA is an optional presentation and launcher layer, not a requirement for listening.

02 · INSTALLED APP

Use the same player in a standalone window.

The manifest requests standalone display and supplies regular and maskable launcher artwork. On supported devices, installation places PlayGarba in the normal app-launching surface and removes most browser chrome when it opens.

See install instructions →

03 · PHONE + TABLET

The layout changes behaviour, not just size.

On phones, the genre strip scrolls horizontally while Explore opens the dedicated responsive catalogue. iPad portrait and landscape have their own responsive treatment, and safe-area spacing protects controls around notches, the Dynamic Island and home indicator.

04 · DESKTOP

More room, same listening model.

On larger screens, the courtyard composition stays visible, the player remains centred, and search, share, favourites, queue and Nonstop stay as compact utilities around it.

05 · CONNECTION LOSS

The shell can recover. Music still needs a source.

The installed player can cache its app shell and selected static assets after an online visit. External audio and video are not silently downloaded, so normal music playback should still be treated as an online activity.
