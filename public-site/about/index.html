ABOUT

A home for Gujarati Garba.

PlayGarba is a focused catalogue and player for Garba songs, artists, releases and longer Nonstop sets.

Listen now ↗ GitHub ↗

GARBA FIRST

One kind of music, treated properly.

PlayGarba is not trying to become a general music service. Songs, artists, releases and longer sets are organised around Gujarati Garba so the catalogue stays understandable.

Traditional, Dandiya, Devotional, Folk, Sanedo and Fusion are six ways into the same catalogue.

THE PLAYER

Keep the interface quieter than the music.

Explore, favourites, queue and Nonstop sit around the player rather than becoming separate products. Primary controls stay stable, unavailable states stay clear and the layout adapts for phone, tablet and desktop.

Playback uses verified YouTube routes, with the video collapsed by default.

THE PROJECT

Open and inspectable.

The public repository contains the player, catalogue data, PWA implementation, validation scripts and project documentation.
