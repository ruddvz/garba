PlayGarba FAQ.

START

Using PlayGarba.

Which URL should I use for listening?

Use live.playgarba.com for the player and Explore catalogue. Use playgarba.com for the public website and guides.

Do I need an account?

No account step is required to open the current public player.

Do I need to install PlayGarba?

No. Installation is optional. The live player works in a supported browser.

LISTENING

Finding and playing Garba.

What are the six worlds?

Traditional, Dandiya, Devotional, Folk, Sanedo and Fusion.

Where do I search for a song or artist?

Use Explore in the live player. It opens the dedicated catalogue.

What is Nonstop?

Nonstop is for longer Garba sets and continuous releases.

Where does the music play from?

PlayGarba uses verified YouTube routes for playback.

Will the YouTube video always be visible?

No. It stays collapsed by default and can be opened from the YouTube control.

Why might a catalogue item be unavailable?

If a verified YouTube route has not been added yet, the item can remain unavailable instead of falling back to another music service.

INSTALL + OFFLINE

Home screen, desktop and connection loss.

Which address should I install?

Install live.playgarba.com, not the public website.

Where are the device instructions?

Use the install guide for iPhone, iPad, Android, Chrome and Edge.

Does installing PlayGarba make music available offline?

No. The interface can cache selected files, but YouTube playback still needs an internet connection.

What should I do if the player looks stale?

Reconnect to the internet and reopen or refresh the live player.
