GOOD TO KNOW

It is still the same player.

The installed version opens PlayGarba in a standalone app-style window where the browser supports it. You do not get a different catalogue or account.

UPDATES

No routine reinstall.

The web app can pick up newer player files and catalogue data through the browser’s normal web-app update path.

OFFLINE

Installed does not mean downloaded music.

The interface can cache selected files, but YouTube playback still needs an internet connection. You can remove the installed app at any time and keep using live.playgarba.com in a browser.
